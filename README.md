# 🌟 Dr. A.P.J. Abdul Kalam – Tribute Page

A responsive and visually appealing tribute website dedicated to **Dr. A.P.J. Abdul Kalam**, one of India's most respected scientists and leaders.

## 🌐 Live Website

👉 **[View Live Website](https://primekhalid.github.io/-Dr.-A.P.J.-Abdul-Kalam-Tribute-Page/)**

> Replace `YOUR-USERNAME` with your GitHub username.

## 📌 About the Project

This project is created as part of the **Web Development & Designing – Level 2** task.

The website presents the life, achievements, inspiration, and famous quotes of **Dr. A.P.J. Abdul Kalam** in a clean and responsive design.

## ✨ Features

* 📱 Fully responsive design
* 👤 Hero section with Dr. A.P.J. Abdul Kalam
* 📖 Biography / About section
* 🏆 Key achievements timeline
* 💬 Inspirational quote section
* 🌟 Inspiration and legacy section
* 🎨 Clean and modern UI
* 📐 Mobile-friendly layout
* 🔤 Multiple font styles

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* CSS Flexbox
* CSS Grid
* Responsive Media Queries
